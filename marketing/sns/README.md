# 메모킹 SNS 소개 자료

흔한 메모 기능(자동 저장, 색, 태그, 검색 등)은 빼고, 메모킹에만 있는 10가지를 소개한다.
화면은 모두 실제 앱을 띄워 찍었다 (`npm run shots:sns` → `out/sns`, 여기 `shots/` 로 복사).

| 파일 | 내용 |
|---|---|
| `cards/s01.png` ~ `s12.png` | 인스타그램 카드 12장 (1080x1350, 4:5) |
| `carousel.html` | 카드 원본. 고친 뒤 `node marketing/sns/render.mjs` 로 다시 그림 |
| `shots/` | 앱 화면 (2배 화질) · `scenes.json` 은 창 위치 (왕관 · 테이프 스티커 합칠 때) |

다시 찍기: `xvfb-run -a -s "-screen 0 2560x1600x24" npm run shots:sns -- --no-sandbox` (Windows 에서는 `npm run shots:sns`) → `out/sns/*.png` 를 `shots/` 로 복사 → 투명 테두리 자르기 → `render.mjs`

## 카드 순서

1. 표지: 메모 앱인데, 이것까지 해요
2. 매직키 (Ctrl+Alt+Space): 메모, 메모와 PC 파일 찾기, 계산, 웹 검색, AI에게 묻기
3. 메모 단축키 (Ctrl+Alt+1~9): 자주 쓰는 문구를 어디서든 복사
4. 매직 카피, 영역 캡처 (Ctrl+Alt+C): 고른 글을 출처까지, 두 번 누르면 화면 잘라 메모로
5. 메모 스택: 서류철 색인 탭
6. 왕관과 테이프: 늘 위에, 바탕화면에
7. 손 메모와 주석: 글 위에 펜으로
8. Work / Life
9. 알림 보관함: 지운 알림, 카카오톡 알림 창까지
10. 회상: 사진 달력, 그날의 스크랩북
11. 내 드라이브의 파일 + AI 연결
12. 마무리: PC와 휴대폰에서 같은 메모

## 인스타그램 (카드 12장 + 캡션)

```
메모 앱인데, 이것까지 해요.

흔한 메모 기능 말고 메모킹에만 있는 10가지를 모았어요.

Ctrl+Alt+Space 하나로 메모, 파일 찾기, 계산, AI 질문까지.
자주 쓰는 문구는 Ctrl+Alt+숫자로 어디서든 복사.
지운 알림도, 카톡 알림도 남는 알림 보관함.

넘겨 보면서 써 보고 싶은 걸 골라 보세요.
나중에 다시 보려면 저장해 두세요.

설치 링크는 프로필에 있어요. Windows PC, 안드로이드.

#메모킹 #메모앱 #생산성 #업무효율 #윈도우 #스티커메모 #노트앱 #일잘러
```

대체 텍스트(카드 1장마다): "메모킹 소개 카드, [카드 제목]. 실제 앱 화면이 함께 있어요."

```
메모킹 알림 보관함은 지운 알림, 카톡 알림 창까지 모아 둬요.

```
