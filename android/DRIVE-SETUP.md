# Google Drive 동기화 준비 (처음 한 번, 10분 정도)

메모킹 안드로이드가 내 Google Drive의 메모 폴더(PC 메모킹이 쓰는 `내 드라이브 › 메모킹`)를 직접 읽고 쓰려면, 구글에 "이 앱이 내 Drive를 써도 돼요"라고 등록한 **OAuth 클라이언트**가 하나 있어야 합니다. 내 구글 계정으로 내 Google Cloud 프로젝트에 만들기 때문에 메모는 나와 구글 사이에서만 오갑니다(메모킹 서버 같은 것은 없어요).

> 화면 이름은 Google Cloud 콘솔이 바뀌면서 조금씩 다를 수 있어요. 메뉴 이름이 다르면 비슷한 이름을 찾으세요.

## 1. 프로젝트 만들기

1. PC 브라우저에서 <https://console.cloud.google.com> 에 PC 메모킹과 **같은 구글 계정**으로 로그인
2. 위쪽 프로젝트 선택 › **새 프로젝트** › 이름 `메모킹` › 만들기

## 2. Google Drive API 켜기

1. 왼쪽 메뉴 › **API 및 서비스 › 라이브러리**
2. `Google Drive API` 검색 › **사용**

## 3. 동의 화면 (Google 인증 플랫폼)

1. 왼쪽 메뉴 › **API 및 서비스 › OAuth 동의 화면** (또는 **Google 인증 플랫폼 › 시작하기**)
2. 앱 이름 `메모킹`, 사용자 지원 이메일 = 내 이메일 › 대상 **외부** › 연락처 이메일 = 내 이메일 › 만들기
3. **대상(Audience)** 에서 게시 상태를 **프로덕션으로 푸시(앱 게시)** 로 바꿉니다.
   - "테스트" 상태로 두면 로그인이 **7일마다 끊겨요** (구글 규칙). 게시해도 다른 사람이 쓰는 것이 아니라 내 계정에서만 쓰니 괜찮아요.
   - 구글의 앱 확인(심사)은 받지 않아도 됩니다. 대신 휴대폰에서 로그인할 때 **"Google에서 확인하지 않은 앱"** 화면이 나오면 **고급 › 메모킹(으)로 이동(안전하지 않음)** 을 누르면 돼요. 내가 만든 앱이라 나오는 안내예요.

## 4. OAuth 클라이언트 만들기

1. 왼쪽 메뉴 › **API 및 서비스 › 사용자 인증 정보** (또는 **Google 인증 플랫폼 › 클라이언트**)
2. **사용자 인증 정보 만들기 › OAuth 클라이언트 ID**
3. 애플리케이션 유형: **데스크톱 앱** (안드로이드가 아니라 데스크톱이에요 — 메모킹은 휴대폰 브라우저로 로그인하는 방식이라 이 유형을 씁니다), 이름 `메모킹 안드로이드` › 만들기
4. 나오는 **클라이언트 ID**(`….apps.googleusercontent.com`)와 **클라이언트 보안 비밀번호**(`GOCSPX-…`)를 복사해 둡니다

## 5. 메모킹에 넣기 (둘 중 하나)

**A. 휴대폰에서 바로** — 메모킹 › 처음 화면의 **Google Drive와 동기화** (또는 설정 › Google Drive 동기화 › 연결하기) › 클라이언트 ID·보안 비밀번호 붙여 넣기

**B. APK 에 넣어 두기** (휴대폰마다 다시 넣지 않아도 됨) — GitHub 저장소 › Settings › Secrets and variables › Actions › **New repository secret**

| 이름 | 값 |
|---|---|
| `MEMOKING_GOOGLE_CLIENT_ID` | 클라이언트 ID |
| `MEMOKING_GOOGLE_CLIENT_SECRET` | 클라이언트 보안 비밀번호 |

그다음 Actions › Android APK › **Run workflow** 로 다시 빌드한 APK를 설치합니다. (직접 빌드할 때는 `android/local.properties` 에 `memoking.googleClientId=…`, `memoking.googleClientSecret=…`)

## 6. 연결하기

1. 메모킹 › **Google Drive와 동기화** › **Google 계정으로 로그인**
2. 브라우저에서 PC 메모킹과 같은 계정 고르기 › 허용 › **메모킹으로 돌아가기**
3. 폴더 목록에서 **메모킹** (`PC 메모 폴더` 표시) 고르기 › **"메모킹" 폴더 쓰기**

첫 동기화 때 PC의 메모·첨부를 모두 받아 옵니다. 그다음부터는 앱을 열 때, 메모를 고친 뒤 몇 초, 화면을 보는 동안 1분마다, 앱이 꺼져 있을 때는 15분쯤마다 맞춥니다.

## 동기화 규칙

- PC 쪽은 따로 할 일이 없어요. **Google Drive for desktop** 이 PC 폴더와 Drive를 맞추고, 메모킹 안드로이드가 Drive와 휴대폰을 맞춥니다.
- **한쪽에서만 고친 메모** → 다른 쪽에 그대로 반영
- **PC와 휴대폰에서 같은 메모를 함께 고친 경우** → PC 쪽 내용을 남기고, 휴대폰에서 쓴 내용은 `제목 (휴대폰 충돌 2026-10-03 1422).md` 사본으로 남겨 둡니다 (어느 쪽 글도 잃지 않음)
- **지운 메모** → 데스크탑과 같이 `_memoking/trash/` 로 옮겨지고, Drive 에서 지워지는 파일은 Drive 휴지통으로 가서 30일 동안 되살릴 수 있어요
- `_memoking/index.json` (LLM 인덱스)은 기기마다 따로 만들어서 서로 덮어쓰지 않아요
- 한쪽에서 파일이 한꺼번에 많이 사라지면(폴더를 잘못 골랐거나 연결 문제) 아무것도 지우지 않고 동기화를 멈춥니다

## 문제가 생기면

| 보이는 말 | 할 일 |
|---|---|
| Google Cloud 프로젝트에서 Google Drive API를 켜 주세요 | 2단계를 다시 확인 |
| Google Drive 로그인이 끊겼어요 | 설정 › 연결하기로 다시 로그인. 7일마다 끊기면 3단계의 "앱 게시"를 확인 |
| redirect_uri_mismatch / invalid_client | 4단계의 애플리케이션 유형이 **데스크톱 앱**인지, ID·비밀번호를 정확히 붙여 넣었는지 확인 |
| 액세스 차단됨: 메모킹에서 Google 인증 절차를 완료하지 않았습니다 | 3단계에서 앱을 게시하지 않고 테스트 상태라면 **테스트 사용자**에 내 Gmail을 추가하거나 앱을 게시 |
