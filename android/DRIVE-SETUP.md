# Google Drive 동기화 준비

## 사용자: 할 일 없음

메모킹 › **Google Drive와 동기화(연결하기)** 를 누르고 **PC 메모킹과 같은 계정 → 허용** 만 누르면 끝입니다. 폴더는 메모킹이 알아서 찾아요 — Drive 의 **메모킹 동기화** 폴더가 있으면(PC 가 먼저 만들었으면) 그 폴더, 없으면 새로 만들고, 지금 기기의 메모도 함께 올려요. 비밀번호 입력도, 폴더 고르기도, 설정값 입력도 없어요. (다른 폴더를 쓰고 싶으면 연결한 뒤 **폴더 변경**)

> **메모킹은 Drive 전체를 보지 않아요.** 메모킹이 만든 폴더·파일만 봅니다 (Google 권한 `drive.file`). 그래서 Drive 웹사이트나 Google Drive 데스크탑 앱으로 넣은 파일은 메모킹에 보이지 않고, 폴더 목록에도 **메모킹(PC·휴대폰)이 만든 폴더만** 나와요. PC 와 휴대폰은 둘 다 메모킹이 직접 Drive 와 맞춰야 서로의 메모가 보입니다 (아래 "PC 메모킹").

## 개발자(앱 주인): 처음 한 번만 (5분)

구글은 Drive에 접근하는 앱이 어느 Google Cloud 프로젝트에 등록돼 있어야 권한을 줍니다. 메모킹 앱을 **한 번만** 등록하면 그 뒤로 이 APK를 쓰는 모든 휴대폰이 위처럼 바로 연결됩니다. 복사해서 앱에 붙여 넣을 값은 없어요 — 구글이 앱의 **패키지 이름 + 서명**으로 알아봅니다.

> 등록하기 전에 연결을 누르면 "이 앱이 아직 Google에 등록되지 않았어요" 라고 나옵니다.

1. <https://console.cloud.google.com> 에 구글 계정으로 로그인 → 위쪽 프로젝트 선택 › **새 프로젝트** › 이름 `메모킹` › 만들기
2. **API 및 서비스 › 라이브러리** › `Google Drive API` 검색 › **사용**
3. **API 및 서비스 › OAuth 동의 화면** (또는 **Google 인증 플랫폼 › 시작하기**)
   - 앱 이름 `메모킹`, 지원 이메일·연락처 이메일 = 내 이메일, 대상 **외부** › 만들기
   - **대상(Audience)** 에서 **앱 게시(프로덕션으로 푸시)** — "테스트" 상태로 두면 연결이 7일마다 끊기고, 테스트 사용자로 넣은 계정만 쓸 수 있어요
   - **데이터 액세스(범위)** 에 `.../auth/drive.file` ("이 앱에서 사용하는 Google Drive 파일만") 하나만 넣어요. 예전 안내대로 `.../auth/drive` 를 넣어 두었다면 지워 주세요 — `drive` 는 구글의 "제한 범위"라 공개 배포(Play 스토어)에 해마다 유료 보안 심사가 필요하고, `drive.file` 은 필요 없어요
4. **사용자 인증 정보 만들기 › OAuth 클라이언트 ID** (또는 **Google 인증 플랫폼 › 클라이언트 › 클라이언트 만들기**)
   - 애플리케이션 유형: **Android**
   - 패키지 이름: `com.memoking.app`
   - SHA-1 인증서 디지털 지문: `F9:5D:68:E1:8A:49:78:D8:2B:B2:16:CF:0F:6F:D6:D1:99:7D:F9:59`
   - 만들기 — 끝. (나오는 클라이언트 ID는 어디에도 넣지 않아도 돼요)

SHA-1 은 저장소에 고정한 서명 키(`android/app/debug.keystore`)의 값이라, GitHub Actions 가 만드는 APK 와 직접 빌드한 APK 모두 같습니다. 서명 키를 바꾸면 4단계를 새 SHA-1 로 다시 해야 해요:
`keytool -list -v -keystore android/app/debug.keystore -storepass android | grep SHA1`

### 연결할 때 보이는 안내

구글의 앱 확인(브랜드 확인)을 받지 않았으면, 허용 화면 전에 **"Google에서 확인하지 않은 앱"** 이 한 번 나올 수 있어요. **고급 › 메모킹(으)로 이동** 을 누르면 됩니다. `drive.file` 은 민감하지 않은 범위라 공개 배포 전에 앱 이름·로고·개인정보처리방침만 확인받으면 이 안내가 사라집니다.

## PC 메모킹: Google Drive 앱 없이 로그인으로 동기화

PC 에 **Google Drive 데스크탑 앱(Google Drive for desktop)을 설치하지 않아도** 메모킹이 직접 Drive 와 맞출 수 있어요. 휴대폰과 맞추려면 **이 방법을 써야 해요** — Google Drive 데스크탑 앱(`G:\내 드라이브\메모킹`)이 올린 메모는 휴대폰 메모킹이 볼 수 없어요 (메모킹이 만든 파일만 보므로).

**개발자(앱 주인) — 처음 한 번:** 위와 같은 Google Cloud 프로젝트에서

1. **Google 인증 플랫폼 › 클라이언트 › 클라이언트 만들기** (또는 사용자 인증 정보 만들기 › OAuth 클라이언트 ID)
2. 애플리케이션 유형: **데스크톱 앱** · 이름 `메모킹 PC` › 만들기
3. 나온 **클라이언트 ID** (`….apps.googleusercontent.com`) 와 **클라이언트 보안 비밀번호** (`GOCSPX-…`) 를 적어 둡니다

설치 파일에 미리 넣어 두면 사용자는 붙여 넣을 필요가 없어요: 저장소 **Settings › Secrets and variables › Actions** 에 `MEMOKING_GOOGLE_CLIENT_ID` · `MEMOKING_GOOGLE_CLIENT_SECRET` (위 값, 휴대폰 APK 와 같은 값) 을 넣으면 GitHub Actions 가 만드는 PC 설치 파일과 APK 에 함께 들어갑니다.

**PC 에서:** 메모킹 › 설정 › **Google Drive 동기화 › 연결하기**

1. (설치 파일에 연결 정보가 없을 때만, 처음 한 번) 위 클라이언트 ID·보안 비밀번호를 붙여 넣고 **저장하고 로그인**
2. 기본 브라우저가 열리면 **휴대폰과 같은 구글 계정** 으로 로그인 › (확인하지 않은 앱 안내가 나오면 **고급 › 메모킹(으)로 이동**) › **허용**
3. 메모킹으로 돌아오면 저절로 **메모킹 동기화** 폴더(휴대폰이 먼저 만들었으면 그 폴더, 없으면 새로)와 맞추기 시작해요
4. 첫 동기화가 끝나면 끝 — 이후 메모를 고치면 몇 초 뒤, 그리고 1분마다 자동으로 맞춥니다. 설정에 마지막 동기화 시각이 보여요

- 지금 메모 폴더가 Google Drive 데스크탑 앱 폴더(`내 드라이브` 안) 이면, 그 메모를 **문서\메모킹** 폴더로 **복사**해서 맞추고 새 Drive 폴더로 올립니다. 원래 폴더(`G:\내 드라이브\메모킹`)는 그대로 남으니 백업으로 두었다가, 잘 맞는 것을 확인한 뒤 지워도 돼요.
- 처음 화면(메모 폴더 고르기)에도 **Google 계정으로 로그인해서 동기화하기** 버튼이 있어요.
- 로그인 정보는 이 PC 에만, Windows 암호화로 감싸서 둡니다 (`%APPDATA%\MemoKing\google-auth.json`). 연결 끊기를 누르면 구글 쪽 권한도 거둡니다.
- 앱이 **테스트** 상태라면, 쓰는 구글 계정이 **테스트 사용자** 에 들어 있어야 해요 (안드로이드와 같음).
- 붙여 넣는 대신 미리 넣어 두려면: 환경 변수 `MEMOKING_GOOGLE_CLIENT_ID` / `MEMOKING_GOOGLE_CLIENT_SECRET`, 또는 `desktop/google-client.json` (`{ "id": "…", "secret": "…" }`, git 에는 올라가지 않음).

## 예비: Google Play 서비스가 없는 휴대폰

구글 계정 연결을 쓸 수 없는 휴대폰(일부 중국판 등)에서는 연결 화면의 **다른 방법: 브라우저로 로그인** 으로 연결합니다. 이때는 같은 프로젝트에 **데스크톱 앱** 유형 OAuth 클라이언트를 하나 더 만들어, 그 클라이언트 ID·보안 비밀번호를 앱에 붙여 넣거나 GitHub Secrets(`MEMOKING_GOOGLE_CLIENT_ID`, `MEMOKING_GOOGLE_CLIENT_SECRET`)에 넣어 APK에 담습니다.

## 동기화 규칙

- PC 쪽은 둘 중 하나: **Google Drive for desktop** 이 PC 폴더와 Drive 를 맞추거나, PC 메모킹이 직접 로그인해서 맞춥니다(위). 메모킹 안드로이드는 Drive 와 휴대폰을 맞춥니다.
- PC 메모킹이 직접 맞출 때 PC 와 Drive 양쪽에서 같은 메모를 고쳤으면, Drive 쪽을 남기고 PC 에서 쓴 내용은 `제목 (PC 충돌 …).md` 사본으로 남깁니다
- **한쪽에서만 고친 메모** → 다른 쪽에 그대로 반영
- **PC와 휴대폰에서 같은 메모를 함께 고친 경우** → PC 쪽 내용을 남기고, 휴대폰에서 쓴 내용은 `제목 (휴대폰 충돌 2026-10-03 1422).md` 사본으로 남깁니다 (어느 쪽 글도 잃지 않음)
- **메모를 열어 쓰는 중에 다른 기기 변경이 들어온 경우** (PC·휴대폰 같음) → 지금 쓰는 글은 그 메모에 저장하고, 들어온 내용은 `제목 (다른 기기 10월 5일 08:34).md` 사본 메모로 따로 둡니다
- **지운 메모** → 데스크탑과 같이 `_memoking/trash/` 로 옮겨지고, Drive 에서 지워지는 파일은 Drive 휴지통으로 가서 30일 동안 되살릴 수 있어요
- `_memoking/index.json` (LLM 인덱스)은 기기마다 따로 만들어서 서로 덮어쓰지 않아요
- 한쪽에서 파일이 한꺼번에 많이 사라지면(폴더를 잘못 골랐거나 연결 문제) 아무것도 지우지 않고 동기화를 멈춥니다

## 문제가 생기면

| 보이는 말 | 할 일 |
|---|---|
| 이 앱이 아직 Google에 등록되지 않았어요 | 개발자 4단계 (패키지 이름·SHA-1 이 정확한지) |
| Google Cloud 프로젝트에서 Google Drive API를 켜 주세요 | 개발자 2단계 |
| Google Drive 권한을 다시 허용해 주세요 | 설정 › Google Drive 동기화 › 연결하기. 7일마다 반복되면 개발자 3단계의 "앱 게시" |
| 액세스 차단됨 / 이 앱은 테스트 중 | 개발자 3단계에서 앱을 게시하거나, 테스트 사용자에 내 Gmail 추가 |

## 예전 방식(Drive 전체 권한)에서 바꿀 때 — 한 번만

0.10.8 (휴대폰) · 0.18.14 (PC) 부터 메모킹은 자기가 만든 파일만 봐요. 예전 버전으로 연결해 둔 PC·휴대폰은 업데이트하면 **"Google Drive 동기화를 다시 켜 주세요"** 가 한 번 떠요. 메모는 PC·휴대폰에 그대로 있어요.

1. **PC 먼저:** 안내의 **다시 연결** → 브라우저에서 **허용** — 끝
   - Google Drive 데스크탑 앱 폴더(`G:\내 드라이브\메모킹`)에 있던 메모가 **문서\메모킹** 으로 복사되고 새 **메모킹 동기화** 폴더로 올라가요 (원래 폴더는 그대로)
2. **휴대폰:** 안내의 **연결** (또는 설정 › Google Drive › 연결하기) → **허용** — 끝
   - PC 가 만든 **메모킹 동기화** 폴더를 찾아 맞추고, 휴대폰에만 있던 메모도 올려요. 같은 메모는 하나로, 내용이 다르면 "(휴대폰 충돌 …)" 사본으로 둘 다 남아요
3. 휴대폰이 PC 와 다른 **메모킹 동기화** 폴더를 새로 만들었다면(구글이 PC 와 휴대폰을 다른 앱으로 보는 경우) 메모가 서로 보이지 않아요 — 개발자에게 알려 주세요. 두 클라이언트가 **같은 Google Cloud 프로젝트** 에 있는지 먼저 확인해요
4. (선택) <https://myaccount.google.com/permissions> 에서 예전 **메모킹** 권한이 남아 있으면 지워도 돼요 (PC 는 메모킹이 알아서 돌려줘요)
