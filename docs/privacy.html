개인정보처리방침

메모킹(MemoKing) · 시행일 2026년 10월 3일

요약 — 메모킹은 운영하는 서버가 없습니다. 메모·첨부·알림 기록은 사용자의 기기와 사용자가 고른 저장 공간(예: 사용자 본인의 Google Drive)에만 있고, 개발자를 포함한 누구에게도 보내지지 않습니다. 광고·분석·추적 도구를 쓰지 않습니다.

1. 다루는 정보

  • 메모와 첨부 파일: 사용자가 쓴 메모(마크다운 파일)와 넣은 사진·파일. 사용자가 고른 메모 폴더에 저장됩니다.
  • Google Drive 파일 (Android, 사용자가 연결한 경우): 사용자가 고른 Google Drive 폴더 안의 메모·첨부 파일을 읽고 쓰고 지워 휴대폰과 동기화합니다. 이를 위해 Google 계정의 Drive 접근 권한(https://www.googleapis.com/auth/drive)을 요청하며, 고른 메모 폴더 밖의 파일은 동기화하지 않습니다. 폴더 고르기 화면에서는 폴더 이름 목록만 읽습니다.
  • Google 계정 이메일 주소: 어떤 계정으로 연결했는지 설정 화면에 보여 주기 위해서만 기기에 저장합니다.
  • 다른 앱 알림 (Android 알림 보관함, 사용자가 켠 경우): 알림을 보낸 앱 이름과 알림의 제목·내용·시각, 앱 아이콘. 기기 안 메모킹 저장 공간에만 보관되고, 메모 폴더나 Google Drive 로는 보내지 않습니다. 사용자가 고른 앱은 모으지 않습니다.
  • 링크 미리보기: 메모에 붙여 넣은 웹 주소의 페이지 제목·설명·대표 사진을 그 웹사이트에서 직접 받아 메모 폴더에 저장합니다.

2. 이용 목적

위 정보는 메모를 쓰고 보관하고, 사용자의 기기들 사이에서 같은 메모를 보이게 하고, 예약 알림과 알림 보관함 기능을 제공하는 데에만 씁니다. 그 밖의 목적(광고, 분석, 판매, 학습 등)으로 쓰지 않습니다.

3. 제3자 제공·전송

메모킹은 정보를 개발자나 제3자에게 보내지 않습니다. Google Drive 와 주고받는 데이터는 사용자 본인의 Google 계정과 Google 사이에서만 오가며, Google 의 개인정보처리방침이 적용됩니다.

4. Google 사용자 데이터

Google API 로 받은 정보의 이용·전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. Google 사용자 데이터를 사람이 열람하거나, 광고에 쓰거나, 다른 곳에 팔거나 옮기지 않습니다.

5. 보관과 삭제

  • 메모와 첨부는 사용자가 지울 때까지 메모 폴더에 남고, 지운 메모는 메모 폴더의 휴지통에 정해진 기간 보관된 뒤 영구 삭제됩니다.
  • 알림 보관함은 최근 알림 3,000개까지 보관하며, 앱에서 하나씩 또는 한 번에 지울 수 있습니다.
  • 설정의 "연결 끊기"로 Google Drive 연결을 끊을 수 있고, Google 계정 설정(https://myaccount.google.com/permissions)에서도 권한을 거둘 수 있습니다.
  • 앱을 지우면 기기 안 메모킹 저장 공간(알림 보관함, 설정)이 함께 지워집니다.
