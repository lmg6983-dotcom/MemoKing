메모킹 MemoKing

폴더에 마크다운 파일로 보관하는 스티커 메모 앱 · Windows · Android

메모킹은

  • 메모 하나를 내가 고른 폴더 안의 마크다운 파일 하나로 보관해요. 메모는 언제나 내 파일이에요.
  • Windows 에서는 스티커 메모 창으로, Android 에서는 휴대폰 화면에 맞춰 같은 메모를 써요.
  • 휴대폰 앱은 Google Drive 의 메모 폴더와 직접 동기화해서 PC 와 같은 메모를 보여 줘요.
  • 서식·체크리스트·사진·파일·태그·예약 알림·메모 연결, 지운 메모 휴지통, 알림 보관함(휴대폰)을 지원해요.
